\abstract{\textbf{Motivation:}
%One of the critical challenges we face in understanding malarias epidemiology is that patients are often infected by more than one parasite strain (a.k.a mixed infection).
As a state-of-the-art method for malaria parasite genome deconvolution, the program {\tt DEploid} takes mixed genome sequence and estimates the number of different strains in a sample, the proportion of each strain and their sequences from a set of reference strains. The program output provides a unique opportunity for researchers to study the epidemiology of infectious diseases. However, the complexity of {\tt DEploid} is $\mathcal{O}(lm^2)$, where $m$ is the number of reference strains and $l$ is the number of sites. As a result, this method does not scale well with reference panels of many strains.
\\
\textbf{Results:}
To improve the scalability issue with the number of reference strains, we present an upgraded version --- {\tt DEploid-LASSO}, which can take thousands of reference strains, shrink and optimise for the target. With several new adjustments to the pipeline, we introduce the latest best practice --- {\tt DEploid-Best} for unknown mixed genome deconvolution.
\\

\section{Introduction}

Deconvolution of mixed parasite genome is critical for understanding malarias epidemiology. However, this task is remains challenging for serveral reasons: unknown number of strains and unknown abundance of each strain, sequence error, and lack of reference strains and highly variable recombination rate. Moreover, mixed infection can be classified as super-infections transmitted by multiple mosquitoes or co-infections transmitted by a single mosquito. In the latter case, parasites undergo sexual recombination within the mosquito. Distinguishing different mixed infection scenarios is difficult but crucial for mapping malaria transmission processes. As super-infections reflect transmission intensity and co-infections does not.

To formalize our problem, a mixed infection can be completely described by the number of co-existing strains $k$, their relative proportions $p$, within sample relatedness $r$ and their associated haplotypes $h$. All four variables describe different biological scenarios and can be studied jointly \citep{Galinsky2015,Jack2016,Henden2016} or independently \citep{Chang2017}. To our knowledge, {\texttt DEploid} \citep{Zhu2017,Zhu2019} is the only software package that can examine all four parameters under the same framework. {\tt DEploid} uses imbalanced allele frequencies to infer the number of strains and their relative proportions. The program conditions on haplotype structures within a reference panel as prior information to inferring strain sequences and estimates genome-wide in-sample relatedness. These outputs will allow researchers to study mixed malaria infections with an unprecedented level of detail \citep{Zhu2019,auburn2019a}.

Both \citet{Zhu2017,Zhu2019} have conducted series of simulation studies and validations on both {\it in vitro} and {\it in silico} mixed genomes to mimic real-world epidemiological scenario. We have learned some general lessons in mixed infection deconcolution:
\begin{enumerate}
  \item A reference panel is ideally to be as diverse as possible to capture the key genomic backbones of the mixed genomes. An appropriate reference panel is essential for ensuring high haplotyle qualities.
  \item In the case of balanced mixings, a good reference panel can help to pull strains apart, a less-appropriate reference panel may lead to underestimate $k$.
  \item Several hunderds of high quality single nucleotide polymorphism sites (SNPs) are sufficient to learn $k$ and $p$ instead of the whole genome.
  \item In the case of inbred samples,
  \item In theory, the order of inferring mixed infection parameters $k$, $p$, $r$ and $h$ should be irrelavent. However, in practice, we find some orders are better than the others:
  \begin{enumerate}
    \item It is easier to infer haplotypes $h$ once all the other parameters $k$, $p$, $r$ are fixed.
    \item Given the correct $k$, Ibd improves the proportion inference, as a result, it also improves haplotype inference
    \item Inference of proportions may differ between chromosomes, but the mathematical expression holds
    \item K maybe different, but the expression holds
  \end{enumerate}
\end{enumerate}

All haplotype inference methods are biased by reference panels \cite{Palmer2016}.
An intuitive approach to reduce such bias is to increase the haplotype number of the reference panel.
Ultimately, using a global reference panel will enable us to obtain high-quality haplotypes and investigate gene flows in great detail.
In this project, I use a ``least absolute shrinkage and selection operator'' (LASSO) approach to shrink and optimise the global reference panel.
The program uses key genotype structures to tune the output haplotypes.

In the first attempt, \citet{Zhu2017}'s approach executes \texttt{DEploid} once and deconvluts $k$, $p$ and $h$ at the same time. When applying to the Pf3k dataset, \citet{Zhu2019} improved the pipeline, and , an improved alternative was to seperate the proportion

'DEploid-BEST' executes the deconvolution algorithms in an optimised sequence to best report the number of strains, proportions and haplotypes. The program ('DEploid-Lasso') learns the number of strain with optimised reference panel. It ('DEploid-IBD') then fixes the number of strains and tune the strain proportions with an identity by descent model. Finally, the program ('DEploid-Lasso') fixes the number of strains and proportions, and uses the optimised reference panel again to train and report the haplotypes.
