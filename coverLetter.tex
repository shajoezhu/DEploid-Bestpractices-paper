\noindent\textbf{Summary.}
As a state-of-the-art method for malaria parasite genome deconvolution, the
program \texttt{DEploid} takes read counts from a mixed sample and estimates the
number of strains, their relative proportions and their sequences from a set of
reference strains. This output provides a unique opportunity for researchers to
study the epidemiology of infectious diseases. However, the complexity of
\texttt{DEploid} is $\mathcal{O}(lm^{2})$, where $m$ is the number of reference
strains and $l$ is the number of sites, so it does not scale well to reference
panels with many strains. To address this, we present \texttt{DEploid-LASSO},
which can take thousands of reference strains and shrink and optimise the panel,
together with a revised pipeline that we call \texttt{DEploid-BEST}, the latest
best practice for deconvolving unknown mixed genomes.

\medskip

\noindent\textbf{Why this work fits \emph{Bioinformatics}.}
Mixed-genome deconvolution is central to malaria surveillance and
transmission-mapping, yet routine use of \texttt{DEploid} has been limited by its
quadratic scaling with reference-panel size and by the need to pre-specify the
number of strains. \texttt{DEploid-BEST} removes both bottlenecks: a LASSO step
selects an effective reference panel (so run time is roughly constant as the
panel grows from 10 to 1000 strains), and the strain number is recovered
automatically while matching the accuracy of a correctly specified classical
deconvolution. We believe the tool, its open-source implementation, and the
benchmarking methodology will be of direct practical value to the
bioinformatics and malaria-epidemiology communities that \emph{Bioinformatics}
serves, and we submit it as an Application Note describing readily usable
software.

\medskip

\noindent\textbf{Availability and implementation.}
The open source implementation is freely available at
\url{https://github.com/DEploid-dev/DEploid} under the conditions of the GPLv3
license. \texttt{DEploid-BEST} is implemented in C++ with an R interface.
